# Example data

`example_workflows.csv` holds five illustrative workflows used by the examples and
case studies. The scores were chosen by the author to demonstrate the framework;
they are not measurements or assessments of any real laboratory's workflows.

Columns: `name`, the six domain scores (0 to 10, higher means more ready:
`data_readiness`, `traceability`, `integration`, `human_dependency`,
`exception_handling`, `workflow_stability`) and an optional `notes` column. Use the
same layout to assess your own workflows with `read_workflows()`.
